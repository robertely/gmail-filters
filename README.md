# Gmail Filters

A small collection of Gmail filters used to organize recurring mail.

## Filters

- `appointments/pre-prep.md` — appointment check-in, forms, questionnaires, and other pre-visit preparation
- `appointments/reminders.md` — upcoming appointment reminders
- `noise/account-statements.md` — account and billing statements
- `noise/feedback-requests.md` — optional surveys and feedback requests
- `noise/political-outreach.md` — campaign, party, PAC, and elected-official outreach
- `noise/privacy-policy.md` — privacy-policy, terms, agreement, and disclosure updates
- `orders/delivered.md` — physical package and order delivery notices
- `orders/placed.md` — order-placement and purchase-confirmation messages
- `orders/shipping.md` — order shipping and delivery-status updates
- `payments/confirmations.md` — successful payment confirmations
- `payments/scheduled.md` — upcoming automatic and scheduled payment notices
- `security/sign-ins.md` — account sign-in and new-device security notifications
- `security/verification-codes.md` — one-time verification and authentication codes
